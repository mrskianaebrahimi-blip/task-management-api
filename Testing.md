# API Testing

## Overview

Testing ensures that the API works correctly.

## Test Cases

| Test | Method | Expected Result |
|---|---|---|
| Get all tasks | GET | 200 OK |
| Get task by ID | GET | 200 OK |
| Create task | POST | 201 Created |
| Update task | PUT | 200 OK |
| Delete task | DELETE | 204 No Content |

## Testing Tools

- Postman
- cURL
- Browser

## Testing Rules

- Test valid requests.
- Test invalid requests.
- Check response status codes.
- Verify returned data.
